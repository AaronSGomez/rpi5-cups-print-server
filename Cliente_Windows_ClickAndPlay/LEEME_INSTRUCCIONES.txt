🏴‍☠️ CLIENTE WINDOWS 10 / 11 CLICK & PLAY — PRINT_SERVER_PI5
=============================================================================

Este paquete contiene todo lo necesario para configurar tu equipo Windows
con la impresora HP LaserJet compartida por Raspberry Pi 5.

=============================================================================
1. INSTALACIÓN AUTOMÁTICA (RECOMENDADO — 1 CLIC):
=============================================================================
Para la gran mayoría de usuarios: no necesitas tocar ningún script de consola.

👉 Haz doble clic en el ejecutable:
   INSTALAR_PRINT_SERVER_PI5.exe (icono de bandera pirata)

¿Qué hace de forma automatizada?
• Te pide la IP local de tu Raspberry Pi (si no existe ip_servidor.txt).
• Comprueba la conectividad con CUPS en el puerto 631.
• Instala la impresora en Windows Spooler con el driver óptimo (PCLmS / IPP).
• Registra e inicia el servicio residente Print_Server_Pi5.exe junto al reloj.
• Te permite resolver atascos de papel haciendo clic derecho en el icono pirata
  y pulsando "⚡ Desbloquear y Reanudar Impresora".

=============================================================================
2. CONTROL MANUAL Y SCRIPTS POR LOTES (CARPETA SEPARADA):
=============================================================================
Si prefieres no utilizar el instalador .exe y prefieres ejecutar comandos
manualmente mediante archivos .bat y PowerShell:

👉 Abre la subcarpeta: "Scripts_Ejecucion_Manual"

Allí encontrarás todas las utilidades individuales:
• INSTALAR_IMPRESORA.bat       -> Instalación clásica vía PowerShell.
• REANUDAR_IMPRESORA.bat       -> Desbloqueo rápido tras atascos de papel.
• DESINSTALAR_IMPRESORA.bat    -> Desinstalador limpio para equipos temporales.
• INICIAR_Print_Server_Pi5.bat -> Arranque manual del monitor.
• DETENER_Print_Server_Pi5.bat -> Detención del monitor.
• ACTIVAR_INICIO_AUTOMATICO.bat-> Configurar arranque con Windows.
• PROBAR_NOTIFICACIONES.bat    -> Test de alertas emergentes en pantalla.
