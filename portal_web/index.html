NÚCLEO DE IMPRESIÓN // PUERTO 631

CUPS 2.4.x (Common UNIX Printing System)

Servidor de colas centralizado con protocolo IPP/2.1. Escucha en todas las interfaces de red locales (Port 631) permitiendo a clientes Windows, Linux y Android enviar trabajos crudos (RAW), PWG-Raster o PCLmS sin autenticación restrictiva mediante directivas 'Allow @LOCAL'.

Directorio Conf: /etc/cups/cupsd.conf
Política de Error: ErrorPolicy retry-job
Servicio Systemd: cups.service (active)
Sockets: 0.0.0.0:631 & [::]:631
02 // REPLICATION

Cómo Replicar el Servidor en Otra Raspberry Pi

Proceso de aprovisionamiento automatizado, idempotente y con tolerancia a fallos. Diseñado para ejecutarse en menos de 5 minutos sobre cualquier placa Raspberry Pi con arquitectura ARM64.

01

Preparación del Host

Instala Raspberry Pi OS (64-bit) o Debian 12/13. Conéctate vía SSH, clona el repositorio y define tus credenciales privadas en el archivo de entorno seguro.

git clone https://github.com/AaronSGomez/rpi5-cups-print-server.git
cd rpi5-cups-print-server
cp .env.example .env
02

Ejecución Automatizada

Ejecuta el script modular con privilegios root. Instalará CUPS, HPLIP, Avahi, Samba, configurará udev y enmascarará ipp-usb para evitar colisiones.

# Despliegue en 1 solo comando:
sudo bash setup_cups_server.sh
03

Verificación & Test Físico

Comprueba que el planificador esté activo y la cola no esté pausada. Lanza una página de prueba directa al dispositivo USB por línea de comandos.

lpstat -p -d -v
echo 'Prueba Raspberry Pi' | lp -d HP_LaserJet_M14_M17

04 // CLIENTS

Integración en Equipos del Hogar

Despliegue sin fricción: paquetes ejecutables con auto-elevación para ordenadores Windows y configuración nativa sin apps en teléfonos Android e iOS.

Instalación en 1 Clic (Modo Portátil)

La carpeta portátil Cliente_Windows_ClickAndPlay contiene un lanzador ejecutable que no requiere conocimientos técnicos ni instalación de software de terceros.

  1. Copia la carpeta Cliente_Windows_ClickAndPlay en el ordenador deseado.
  2. Haz doble clic sobre INSTALAR_IMPRESORA.bat.
  3. Acepta la elevación de privilegios de Administrador de Windows (UAC).
  4. El script te solicitará la IP local de tu Raspberry Pi, comprobará el puerto 631 y seleccionará el mejor controlador nativo (PCLmS / Microsoft IPP Class).
  5. Pulsa Enter para enviar una página de prueba.
Tip: Si creas un archivo local ip_servidor.txt con tu IP en la carpeta, el instalador no te pedirá la IP y se instalará en modo 100% silencioso.

Vinculación Manual por Interfaz Gráfica

Si prefieres añadir la impresora mediante el panel de control estándar de Windows:

  1. Presiona Win + I y ve a Bluetooth y dispositivos > Impresoras y escáneres.
  2. Pulsa en Agregar dispositivo y espera 5 segundos hasta que aparezca el enlace azul: "La impresora que deseo no está en la lista".
  3. Selecciona la opción: "Seleccionar una impresora compartida por nombre".
  4. Escribe la URL del servidor:
    http://<IP_RASPBERRY_PI>:631/printers/HP_LaserJet_M14_M17
  5. En el catálogo de drivers, elige: HP > HP LaserJet M14-M17 PCLmS (o Generic PCL6).

Detección Automática (Zero-Config / Mopria)

  1. Conecta tu teléfono a la red Wi-Fi de la vivienda.
  2. Ve a Ajustes > Conexiones > Preferencias de conexión > Impresión (o "Conexión y compartir > Impresión" en Xiaomi).
  3. Comprueba que el Servicio de impresión predeterminado esté Activado.
  4. Abre cualquier documento, foto o PDF y pulsa Imprimir.
  5. La impresora aparecerá automáticamente como HP_LaserJet_M14_M17 @ raspberrypi.

Conexión Manual por IP (Bypass de Aislamiento Wi-Fi)

Si tu router tiene activado el AP Isolation (Aislamiento de clientes) y bloquea los paquetes mDNS:

  1. En Ajustes > Impresión > Servicio predeterminado, pulsa el menú de los 3 puntos verticales.
  2. Selecciona "Agregar impresora" > Por dirección IP.
  3. Introduce la IP de tu Raspberry Pi o la URL completa:
    http://<IP_RASPBERRY_PI>:631/printers/HP_LaserJet_M14_M17
  4. Pulsa Guardar. Quedará vinculada permanentemente.

Apple AirPrint Nativo (iPhone, iPad, Mac)

Gracias a que el demonio Avahi de la Raspberry Pi 5 anuncia el protocolo DNS-SD con subtipos _ipp._tcp y perfiles URF/Raster, los dispositivos Apple no necesitan ninguna aplicación de terceros ni configuración:

  1. Conecta el iPhone o iPad a la misma red Wi-Fi.
  2. En cualquier aplicación (Safari, Fotos, WhatsApp, Mail, Archivos), pulsa el botón Compartir (icono de cuadrado con flecha).
  3. Toca en Imprimir.
  4. En el campo Impresora, verás aparecer instantáneamente HP_LaserJet_M14_M17.
  5. Selecciona el número de copias y pulsa Imprimir en la esquina superior derecha.
